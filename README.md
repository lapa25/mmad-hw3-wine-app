# Подборка вин

Приложение использует сохраненный пайплайн из ДЗ 3. Один порог в боковом меню применяется к оценке одного вина, метрикам и пакетной оценке

## Локальный запуск

Python 3.12. Откройте терминал в папке `wine_app` и выполните команды

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для пакетной оценки нужны 12 столбцов из `test.csv` без `target`. `is_red` равен 1 для красного вина и 0 для белого

## Кэширование

`st.cache_resource` хранит один загруженный пайплайн на сервере. При вызове `joblib.load` без кэша приложение читало бы модель с диска при каждом движении ползунка. `st.cache_data` хранит данные тестовой выборки и рассчитанные вероятности, возвращая копии этих данных. При смене порога приложение использует готовые вероятности и пересчитывает решения и метрики

## Данные

Тестовая выборка получена из [Wine Quality (P. Cortez et al., 2009, CC BY 4.0)](https://archive.ics.uci.edu/dataset/186/wine+quality). В подготовленной для задания версии добавлен признак `is_red`, а оценки от 7 и выше обозначены как `target = 1`. Перед разбиением удалены полные дубли
